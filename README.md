# Centre Optique Chefchaouen

Site vitrine (page unique, HTML/CSS/JS) en 4 langues : FR, EN, AR (RTL), ES.

## À personnaliser (dans `index.html`)
- `CFG` : adresse, téléphone, WhatsApp (format international sans +, ex. 2126XXXXXXXX), horaires, liens Google, Instagram, Facebook, `legalUrl`.
- `BRANDS` / `PRODUCTS` : marques et modèles (les modèles « DEMO » sont à remplacer).
- `IM` : photos, ex. `IM["hero.main"]=["assets/images/hero/main.webp","Texte ALT"]`.
- Vidéo : attribut `data-src` de la balise `<video id="v">` (ex. `assets/videos/centre.mp4`) et poster.
- Remplacer `https://VOTRE-DOMAINE.ma/` (canonical, hreflang) par le vrai domaine.

## Publier avec GitHub Pages
Settings → Pages → Source : `main` / racine.
